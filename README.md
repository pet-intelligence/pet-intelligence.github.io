# Pet Intelligence

Lightweight institutional website for GitHub Pages. Static HTML, CSS and JavaScript; no build or server is required.

Enable Pages for the repository's `main` branch and root directory. Test the GitHub-provided address before configuring the custom domain in repository Settings → Pages.

Contact Us prepares a message for WhatsApp and asks the visitor to send it there. The floating WhatsApp link works without JavaScript. The site has no contact database, research registration, admin editor, embedded video or analytics tracker.

The original design and images are retained in smaller WebP files. Scoptic and Concat are presented as projects in development, with live app links removed.

To update the site, edit the HTML files and assets, then commit the changes. Keep credentials, private archives, customer data and environment files outside this repository.
